# mtDNA heteroplasmy workflow

This repository contains the heteroplasmy-analysis portion of the mitochondrial DNA workflow.

Important note: POD5 processing, basecalling, and the initial methylation-oriented alignment steps are performed in the separate methylation repository. This heteroplasmy repository starts from the extracted mtDNA BAMs generated by that upstream workflow and focuses on reciprocal-orientation SNV calling and QC.

## Scope

This repository contains only code relevant to heteroplasmy analysis under the [code](code) directory. It does not include the methylation/POD5 processing pipeline or unrelated analysis scripts.

## Processing summary

```text
POD5 processing and modified-base calling
    |
    v
methylation repository
    |
    +--> composite SphI/NcoI alignments
    +--> extracted mtDNA-only BAMs
    |
    v
this heteroplasmy repository
    |
    +--> read the SphI-oriented and NcoI-oriented mtDNA BAMs
    |
    +--> collect A/C/G/T counts, depth, strand support, and mean base quality
    |
    +--> evaluate SNV candidates across all callable mtDNA positions
    |
    +--> select the appropriate orientation using reciprocal-reference logic
    |
    +--> apply filters and annotate PASS / candidate / all-site outputs
    |
    +--> export read-level support and generate QC plots
```

## Core computational pipeline

1. Align barcode reads independently to:
   - GRCm39 nuclear + NC_005089.1_SphI_rotated reference
   - GRCm39 nuclear + NC_005089.1_NcoI_rotated reference

2. Extract primary reads assigned to the rotated mtDNA contig from each alignment.

3. Apply mapping-quality and alignment filters.

4. Collect per-position nucleotide evidence independently from both alignments:
   - A/C/G/T counts
   - total depth
   - alternate-allele count
   - forward/reverse alternate support
   - mean alternate-base quality
   - SphI VAF
   - NcoI VAF

5. Calculate candidate heteroplasmy VAF at every callable mtDNA position.

6. Apply core SNV filters:
   - depth >= 100
   - alternate reads >= 5
   - VAF >= 1% and <= 95%
   - alternate reads on each strand >= 2
   - mean alternate base quality >= 20
   - Fisher strand-bias p-value >= 0.001
   - homopolymer/context filter

7. Evaluate reciprocal-reference support:
   - validation-orientation depth >= 100
   - SphI vs NcoI orientation VAF difference <= max(2 percentage points, 25% relative difference)

8. Apply restriction-boundary orientation rules:
   - away from artificial boundaries: use the primary SphI result and require agreement with NcoI
   - near the SphI boundary (canonical positions 10,758-10,759): use the reciprocal NcoI result
   - near the NcoI boundary (canonical positions 9,215-9,216): use the reciprocal SphI result
   - if one orientation is unusable because of its boundary, rescue the site using the valid reciprocal orientation
   - never merge SphI and NcoI depths or allele counts

9. Assign site status and filter reasons.

10. Generate:
    - all-site evidence table
    - candidate SNV table
    - final PASS SNV table
    - PASS VCF
    - JSON summary
    - PASS-variant read-support table
    - heteroplasmy QC plots

11. Export supporting reads for PASS variants and perform manual IGV inspection.

12. Final curated heteroplasmic SNV call set.
